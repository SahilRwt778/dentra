# PDF fonts

Unmodified static TTF files from the official [Noto font archive](https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf):

- Noto Sans Regular and Bold
- Noto Sans Devanagari Regular
- Noto Sans Gurmukhi Regular
- Noto Sans Tamil Regular
- Noto Sans Bengali Regular

`OFL.txt` contains the upstream license. The Nest build copies these assets with the renderer. Only used glyphs are embedded in generated PDFs.
